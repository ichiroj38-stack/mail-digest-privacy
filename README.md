# mail-digest - Privacy Policy

mail-digest is a personal tool used only by its developer to summarize the developer's own incoming email.

- **Data accessed:** read-only access (gmail.readonly) to the developer's own email accounts. The app cannot send, delete, or modify email.
- **Use of data:** sender domain, subject, and a short snippet are summarized and delivered to the developer's private messaging account. Nothing is published.
- **Sharing:** data is not sold or shared with third parties, except that the summarization step is performed by an AI service (Anthropic Claude) on text from which addresses, URLs, phone numbers, and codes have been removed.
- **Storage:** access tokens are stored privately on the developer's server. Email content is not retained.
- **Other users:** this app is not offered to anyone else.
- **Contact:** via the developer's GitHub profile.
